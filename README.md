# IT Equipment Maintenance Management System

Web application for managing IT equipment maintenance, built during my internship at STEG.

## Technologies
- PHP
- MySQL
- XAMPP

## Installation
1. Copy the project folder into `htdocs` (XAMPP).
2. Start Apache and MySQL.
3. Open phpMyAdmin and create a database named `gestion de materiel`.
4. Import `database/gestion_materiel.sql`.
5. Open `http://localhost/employee_maintenance` in your browser.
